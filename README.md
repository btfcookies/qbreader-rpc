# QBReader Discord RPC
> QBReader's Discord RPC is not affiliated with or endorsed by QBReader

This RPC uses PreMiD's extension to display your QBReader activity to Discord. 

## Usage
- Install the [PreMiD Chrome extension](https://chromewebstore.google.com/detail/premid/agjnjboanicjcpenljmaaigopkgdnihi)
- In the [activity library](https://premid.app/library), search for QBReader.
- Install the acitvity
